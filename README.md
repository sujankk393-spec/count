# Counter App

A simple and interactive counter application built using **HTML, CSS, JavaScript, and Bootstrap**. This project demonstrates basic DOM manipulation and event handling in JavaScript.

## 🚀 Features

- **Increase:** Increment the counter by 1.
- **Decrease:** Decrement the counter by 1.
- **Reset:** Set the counter back to 0.
- **Responsive Layout:** Uses Bootstrap for responsive styling.
- **Simple UI:** Clean and minimal interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Custom styling and layout.
- **JavaScript** – Counter functionality and DOM manipulation.
- **Bootstrap 5** – Button styling and responsive layout utilities.

## 💻 How It Works

The application uses JavaScript to maintain a counter variable and update the displayed value whenever a button is clicked.

- Clicking **Increase** adds 1 to the counter.
- Clicking **Decrease** subtracts 1 from the counter.
- Clicking **Reset** changes the counter value to 0.

JavaScript's `getElementById()` method selects HTML elements, while `textContent` updates the displayed counter value.
